# Kodex

> Kodex (Albatross Technologies) operates the Kodex Global Network, the platform crypto exchanges, fintechs, banks, and telecoms use to receive, verify, and respond to law enforcement and government data requests — subpoenas, warrants, and emergency disclosure requests. The same network is available programmatically through the Kodex API: a Verification API, a Targets (Data Production) API, and status webhooks. Authentication is by scoped organization API key in an `X-API-Key` header; API access is provisioned per organization and a demo environment with test data is available for integration testing.

Generated by the API Evangelist enrichment pipeline on 2026-07-19 from Kodex's public surface. Kodex publishes no OpenAPI definition and its interactive reference requires a login, so no operation list beyond the endpoints Kodex names publicly is included here.

## APIs

- [Kodex Verification API](https://docs.kodexapi.com/verifications/reference/): Real-time verification of a law enforcement requester from one email lookup — `POST /v1/verification/lookup` on `https://app.kodexglobal.com`. Returns the agent's standing, their agency's status, and the domain's risk level.
- [Kodex Request Portal API](https://docs.kodexapi.com/request-portal/reference/request-api): Create and manage requests, verified intake, targets, attachments, and messages; automate data production on verified requests — `GET /v1/requests/{request_id}/targets` on `https://app.kodexglobal.com`.
- [Status webhooks](https://www.kodexglobal.com/api): Signed `POST` callbacks to your webhook URL when an agent's credentials or standing change.
